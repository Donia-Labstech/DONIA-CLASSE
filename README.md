# 📚 نظام توزيع التلاميذ على الأفواج — 2027

تطبيق ويب حتمي (Single Page Application) لإدارة وتوزيع تلاميذ المتوسطة على الأفواج التربوية، مع الحفاظ على المسار من السنة الماضية ولوحة تدقيق تلقائية.

## ✨ المميزات الرئيسية

- **معالجة حتمية 100%** — نفس المدخلات تُنتج نفس التوزيع دائماً (لا عشوائية).
- **الحفاظ على المسار** — التلميذ المُرقّى ينتقل آلياً إلى نفس رقم فوجه السابق في المستوى الأعلى.
- **شرط الحماية** — إذا كان رقم الفوج السابق أكبر من المتاح، يُنقل التلميذ لقائمة التوزيع الحر.
- **موازنة ذكية** — توازن الأعداد + الجنس (ذكور/إناث) + المعيدين + نظام التمدرس.
- **تحكم تفاعلي** — إضافة/حذف/نقل أي تلميذ يدوياً مع إعادة توزيع فورية.
- **لوحة تدقيق تلقائية** — تحقق من مطابقة الأعداد + منع التكرار + سلامة البيانات.
- **عرض بملء الشاشة** — اضغط على أي فوج لمشاهدته بملء الشاشة.
- **طباعة احترافية A4** — ترويسة رسمية + خانات توقيع.
- **تصدير Excel** — ورقة إحصاء + ورقة لكل مستوى.
